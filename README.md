# スマート家計簿アプリ

レシート画像や領収書ファイルをアップロードするとAIが内容を推測し、家計簿として記録できるWebアプリケーションです。ユーザーごとのアカウントに紐づけてレシートを管理でき、手入力による登録や分類の修正にも対応しています。

## 主な機能

- メールアドレスとパスワードによるユーザー登録・ログイン
- レシート画像（PNG/JPG/GIF）やテキスト/PDFファイルのアップロード
- アップロードしたレシートから日付・店舗名・金額・カテゴリー・購入詳細をAIが推定
- AI推定結果を編集しながら家計簿に登録、登録後の内容編集も可能
- カテゴリー別の集計と直近のレシート一覧表示
- SQLiteデータベースによるデータ永続化

## 必要環境

- Python 3.10 以上

## セットアップ手順

```bash
python -m venv .venv
source .venv/bin/activate  # Windowsの場合は .venv\\Scripts\\activate
pip install -r requirements.txt
flask --app app:create_app init-db  # 初回のみDB初期化
python run.py
```

起動後、ブラウザで `http://localhost:5000` にアクセスするとログイン画面が表示されます。

## 使い方

1. 「新規登録」からアカウントを作成してログインします。
2. 「レシート登録」で画像やテキストをアップロードすると、AIが内容を推定してフォームに反映します。
3. 日付・店舗名・金額・項目は必須項目なので、AI結果を確認・修正して登録してください。
4. 登録後はダッシュボードでレシート一覧とカテゴリー別集計を確認できます。必要に応じて「編集」から内容を更新してください。

## AI解析について

本アプリのAI機能は、OCRライブラリを必要としない軽量なヒューリスティック解析を採用しています。テキストファイルの内容やファイル名から日付・金額・店舗名を推定し、カテゴリーもキーワードに基づいて自動分類します。精度向上のため、推定結果はすべて手動で修正可能です。
